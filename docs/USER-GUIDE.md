## 1. 30 秒了解你在用什么

**一句话：你说人话，它把话变成策略，用过去几年的真实行情跑一遍，告诉你这个想法在历史上靠不靠谱。**

它不做的两件事，请先记住：

| 不做 | 说明 |
|---|---|
| ❌ 不碰真钱 | 全程模拟，没有开户、没有入金、一个下单接口都没有 |
| ❌ 不预测明天 | 它算的是"如果过去四年你这么做，会怎样"。**过去不代表未来** |

它做的那件事，价值在哪：

> 你脑子里有个想法——"跟着强势股走应该能赚"。这个想法听起来有道理，
> 但到底是真有道理，还是你最近看了几只牛的股票？**只有拿几年的数据跑一遍才知道。**
> 回测就是花 30 秒，把你十年都验证不完的猜想先筛一遍。

## 2. 三个入口，随便挑一个

底部中间那个 **＋** 随时回到首页重新开始。三个入口通向同一个后台，出来的结果完全一样，
区别只是**你要动多少脑子**。

### 入口一：说一句话（最快）

首页输入框，用大白话写你想要什么，点「生成策略并回测」。

> 例：*沪深300里，找最近一个月涨得最猛的20只股票，每月换一次仓*

不用管格式，不用写标点，说错字也没关系。不知道怎么说？点下面三个示例气泡看看套路。

### 入口二：回答 3 个问题（最不容易出错）

首页「不想打字？回答 3 个问题」。

| 步骤 | 问什么 | 说明 |
|---|---|---|
| 第 1 步 | 你想挑什么样的股票？ | 追涨 / 抄底 / 求稳 / 捡便宜 / 看量 / 让模型学，**最多选 2 个** |
| 第 2 步 | 从哪儿挑、买多少、多久换 | 已经按常见值填好，不改也能直接跑 |
| 第 3 步 | 就这样？ | 把最终参数摆给你看，点「开始回测」 |

第 1 步最少选一个才能往下走——因为"挑什么"是策略的核心，这个不能替你猜。

### 入口三：点一张模板（最省事）

首页「或者从这几种开始？」七张卡片，点一下直接出确认卡：

| 卡片 | 挑什么 | 默认池子 |
|---|---|---|
| 🤖 AI 智能预测 | 让模型从量价里自己学规律 | 沪深300 |
| 🚀 追涨强势股 | 最近 20 个交易日涨得最猛的 | 沪深300 |
| 🩹 抄底超跌股 | 最近 5 个交易日跌得多、赌反弹 | 中证500 |
| 🎯 又强又稳 | 追涨 + 求稳，强而不疯 | 沪深300 |
| 🔥 强势又有量 | 在涨的里面再挑成交活跃的 | 沪深300 |
| 🛡️ 低波动防守 | 波动最小的，睡觉踏实 | 中证500 |
| 📈 放量突破 | 成交量突然放大的 | 沪深300 |

模板只是**起点**。出确认卡之后照样可以改池子、改数量、改频率。

> **底部「因子」页**是另一种起点：6 个现成的选股标准，点「用它做策略」直接开跑。
> 注意页面上那行小字——**排序分数目前是示例值**，接入真实评测后才会变成实测结果。

## 3. 怎么说它才听得懂

它只认 **4 个要素**。说全这 4 个，一次就过；漏了也不卡你，后台会按常见值补上并**在确认卡上明确写出来**。

| 要素 | 你怎么说 | 没说会怎样 |
|---|---|---|
| **池子** | 沪深300 / 中证500 / 中证1000 / 全市场 | 默认沪深300，并在假设里告诉你 |
| **挑什么**（必须） | 涨得猛 / 跌得多 / 稳 / 便宜 / 有量 / 让模型学 | **会反问你**，不瞎猜 |
| **买多少只** | "20 只"、"前 30"、"top50" | 默认 20 只 |
| **多久换一次** | 每天 / 每周 / 每月 | 默认每月 |

### 说法对照表

同一个意思有多种说法，都能认：

| 你想要 | 可以这样说 |
|---|---|
| 追涨 | 涨得猛、涨得最凶、强势、动量、趋势、创新高、领涨、热门 |
| 抄底 | 抄底、超跌、跌得狠、跌得多、反弹、反转、跌下来 |
| 求稳 | 稳、波动小、低波、别大起大落、回撤小、保守、不刺激 |
| 捡便宜 | 便宜、低价、低位、估值低、划算 |
| 看量 | 放量、成交活跃、有量、量能、换手、活跃 |
| 让模型学 | 机器学习、AI 预测、智能、训练、深度学习、让模型 |

### 三个实用技巧

**① 可以组合，最多两个。**
"又强又稳" 会同时命中追涨和求稳；"在涨的里面挑有量的" 会命中追涨 + 看量。
组合出来的策略更挑，持仓也更集中。

**② 说"不要什么"它也懂。**
"涨得猛但别太刺激" 里的"别"会被识别成否定，不会把"刺激"算进去。

**③ 数字、频率说得越具体越好。**
"每月换一次"比"经常换"好；"30 只"比"多买几只"好。

## 4. 跑之前一定让你先看一眼（确认卡）

三个入口最后都会弹出同一张卡：**「我理解成了这样」**。这是整个产品最重要的一屏。

```
我理解成了这样
先看看对不对，不对我再改

「在沪深300里，挑最近涨得最猛的 20 只，每月换一次」

标的        沪深300
挑什么      最近 20 个交易日涨得最猛的
买多少      20 只，等权买入
多久换      每月
回测区间    2022-11-24 ~ 2026-11-24
风控        单只不超过 10%

我没听清的地方，先按常见的填了：
· 你没说从哪个池子选，我按沪深300
· 回测区间用最近 4 年

⚠️ 这里用的是「价格位置」近似，不是市盈率/市净率（暂未接入财务数据）

[改一下]              [就按这个跑]
```

### 卡上四类信息，各是什么意思

| 区块 | 作用 | 要不要细看 |
|---|---|---|
| **复述句**（第一行） | 它把你的话翻译回人话 | **必看**。读着别扭就是理解错了 |
| **6 行参数** | 真正会拿去跑的东西 | **必看**。和你脑子里想的不一样就改 |
| **「我没听清的地方」** | 你漏说、它替你补的默认值 | **必看**。这些是它自己决定的，不是你决定的 |
| **⚠️ 提示** | 这个做法的局限、近似、已知缺陷 | **必看**。看不懂也要知道有这么回事 |

### 怎么改

点「改一下」能改四样：**挑法**（换风格）、**池子**、**数量**、**频率**。
改完确认卡实时更新，数字和复述句一起变——不会出现"改了但显示没变"。

不能改的：回测区间固定最近 4 年，风控固定按风险档位算。这两样改了会让结果之间没法比。

> **为什么非要你看一眼？** 因为一句话的理解会有歧义。"最近涨得猛"你可以指 20 天也可以指 60 天。
> 如果不让你确认就跑，你会在看到结果时以为是策略不行，其实是理解错了。
> **这一屏的存在，就是为了让"理解错"发生在花钱之前。**

## 5. 等待时它在干什么

点「就按这个跑」之后是进度页，四步：

| 步骤 | 在干什么 |
|---|---|
| 1. 理解需求 | 识别池子、数量、频率、选股规则 |
| 2. 整理规则 | 把想法变成可计算的选股条件 |
| 3. 安全检查 | 确认没有危险操作（生成的东西要在隔离环境里跑） |
| 4. 回测计算 | 用历史数据逐日推演，算净值 |

通常几十秒。页面下方「正在跑的策略」会把确认过的参数再列一遍，方便你回头对照。

## 6. 结果页九块内容，逐块读懂

从上到下依次是九块。**建议的阅读顺序不是从上到下，而是 ②→③→⑧→④**——
先看人话结论，再看风险，再看它是不是只会背题，最后才看曲线。

### ① 顶部：这个名字和想法

`回测完成` + 策略名 + 一句话描述。右上角星标可以收藏。

### ② 一句话看懂这个策略

一段大白话，实际长这样：

> 这个策略在模拟的这几年里表现稳健不错：平均每年约赚 **18.3%**，同期沪深300约 6.1%。
> 过程中最多亏过 **24.5%**（回撤），风险收益比 0.75。 收益的稳定性也比较好。

它一定会说三件事：**赚多少、跟大盘比怎么样、最多亏多少**。
最后一句还会根据夏普比率补一句"稳不稳"——夏普 > 1 说稳定性好，否则直说"波动稍大，适合能扛得住起伏的人"。

**这是唯一需要你认真读的文字块。** 它把下面所有数字翻译成人话，并且**不会只说好的**——回撤和风险比一定一起给。

### ③ 六个指标卡

| 指标 | 人话 | 怎么看 |
|---|---|---|
| **年化收益** | 平均每年赚多少 | 高不等于好，一定要配着回撤看 |
| **夏普比率** | 每承担一份波动，换来多少收益 | 长期 > 1 算不错，> 2 要怀疑是不是数据太顺 |
| **最大回撤** | 从最高点掉下来最深亏了多少 | **最该看的数字**。你能不能扛住这个数？ |
| **胜率** | 赚钱的天数占多少 | 40%–55% 都正常，高胜率常伴随单次巨亏 |
| **换手率** | 调仓有多频繁 | 越高越吃手续费，实盘会更差 |
| **卡玛比率** | 收益 ÷ 最大回撤 | 衡量"这钱赚得值不值这份惊吓" |

> 六个数里只有两个是"越小越好"：**最大回撤**（亏得少）和**换手率**（省手续费）。
> 其余四个越大越好，但都要配着回撤看。

### ④ 净值走势

一条策略线、一条基准线（沪深300），起点都是 1.00。可以切近1月/近3月/近1年/全部。

**只看一件事：这两条线之间的差距是不是稳定的。**
策略线偶尔上穿、然后又掉回来贴着基准走，说明没有真本事，只是赶上了一段行情。
真正有用的策略，是**差距在多数时间里持续扩大**。

### ⑤ 回撤（亏得最多的时候）

和净值曲线配套看。这条线越深、越久，你越难受。
**重点看"恢复时间"**：如果每次跌下去都要两年才回来，那么实盘中你很可能在半路就放弃了。

### ⑥ 收益贡献

告诉你钱是哪些股票赚的。
**如果 80% 的收益来自一两只股票，这个策略基本等于运气。** 数量越分散越可信。

### ⑦ 持仓分布

前 6 大持仓及权重。看两件事：
- 是不是集中在同一个行业（集中 = 风险大，虽然回测可能很好看）
- 单只权重是不是接近上限（贴着上限说明它想买更多但被风控拦住了）

### ⑧ 分段表现：平时练习 vs 闭卷考试

**这一块是全页最诚实的部分，也是最容易被忽略的。**

| 段落 | 含义 |
|---|---|
| **平时练习（样本内）** | 策略设计和调参时"看过"的那段历史 |
| **闭卷考试（样本外）** | 策略"没见过"的那段历史 |

就像学生：平时练习能考 90 分不稀奇，因为题目都做过。**闭卷考试还能考 80 分，才是真会。**

| 观察 | 结论 |
|---|---|
| 练习和考试差不多 | 相对可信 |
| 练习很好、考试明显变差 | **过拟合**。这个策略是为历史定制的，未来多半不行 |
| 考试比练习还好 | 运气，别太高兴，也别据此加仓 |

### ⑨ 我是这么理解的

列出它的**假设**和**提示**——就是确认卡上那两段，白纸黑字留在这里，方便你回头核对。
如果结果和你预期不符，先回来读这一段，八成的困惑在这里能找到答案。

## 7. 怎么判断一个结果能不能信

看到年化 50% 别激动，按下面这张表逐条排雷。**任何一条中了，这个结果就要打折。**

| 危险信号 | 为什么危险 | 怎么验证 |
|---|---|---|
| **年化 > 40%，回撤还很小** | 真有这种策略，全世界资金都会涌进来 | 看闭卷考试段、看换手率、看是不是只持有了几只票 |
| **闭卷考试明显差于练习** | 过拟合，为历史定制 | 看「分段表现」 |
| **换手率极高（比如月换 100%）** | 回测里手续费算得再全，实盘滑点也更大 | 把换手率 × 双边成本，粗算吃掉多少收益 |
| **收益集中在一两只票** | 运气，不是规律 | 看「收益贡献」 |
| **只在某一段行情里赚钱** | 本质是押注单一市场环境 | 看净值曲线，找那段行情 |
| **持仓高度集中在同行业** | 行业 beta，不是选股能力 | 看「持仓分布」 |
| **样本太短** | 覆盖不了牛熊 | 默认区间是最近 4 年，太短的自己加长 |

### 还有三条硬道理

**① 回测永远比实盘好看。** 因为它不知道你会在最难受的时候放弃。
**② 试的次数越多，越容易撞上好看的结果。** 你调了 20 次参数挑出最好的那个，
这本身就是过拟合——所以别拿"我试了很多次终于找到一个好的"当结论。
**③ 过去的有效性，是未来的必要条件，不是充分条件。**

> 这也是为什么这个产品最终要做**策略观察期**：上线之后每天用**未来真实发生的数据**跑一遍，
> 攒 20 个交易日、60 个交易日的真实记录。那才是没法伪造的证据。
> 回测只回答"这想法历史上说得通"，观察期才回答"它今天还行不行"。

## 8. 看到「演示数据」横幅是什么意思

结果页顶部出现横幅，说明**这不是真实回测**。横幅固定以「以下不是真实回测：」开头，
后面接具体原因，一共六种：

| 横幅说 | 真实原因 | 你能做什么 |
|---|---|---|
| 后端没有连上 | 服务没启动，或地址配错了 | 检查服务是否在跑（见 `DEPLOYMENT.md` §0） |
| 等太久了，任务可能卡住了 | 轮询超时，通常计算资源不够 | 稍后重试；持续出现请看服务日志 |
| 后端出错了，服务暂时不可用 | 服务端 5xx | 稍后重试；持续出现请看服务日志 |
| 请求被拒绝（HTTP 4xx） | 参数不合法或权限问题 | 改一下参数重试；反复出现要报给维护者 |
| 回测服务在这台机器上没跑起来（执行环境不可用） | 沙箱/容器环境缺失（真实计算的前提没有） | 需要维护者按 `DEPLOYMENT.md` §4 配置 |
| 本地演示数据 | 你用纯离线方式打开的页面 | 只看界面可以，**别把这个结果当结论** |

横幅末尾永远有半句：**「为保证体验先展示演示数据，别据此做任何决策。」**

**这不是 bug，是故意的。** 宁可挂个横幅告诉你"这数据是假的"，也不让你拿着假曲线去做决定。

## 9. 它接得住什么，接不住什么

### 接得住

| 类型 | 例子 |
|---|---|
| 趋势类 | "找最近一个月涨得最猛的 20 只" |
| 反转类 | "最近跌得多的 30 只，赌反弹" |
| 波动类 | "波动最小的 20 只，稳一点" |
| 量能类 | "成交量明显放大的" |
| 价格位置 | "价格比过去一年均价低的" |
| 组合 | "又强又稳"、"在涨的里面挑有量的" |
| 模型类 | "让机器学习历史规律来挑" |

### 接不住（会说"这个现在看不了"，不会拿近似的东西冒充）

| 你说 | 为什么会被告知做不到 |
|---|---|
| ROE、净利润、营收、财务指标 | 当前数据只有量价，**没有财报数据** |
| 市盈率、市净率、估值 | 同上。说"便宜"时用的是**价格位置**近似，确认卡会标注 |
| 北向资金、龙虎榜 | 没有资金流向与席位数据 |
| 新闻、研报、市场情绪 | 没有文本数据 |
| 股息率、分红 | 没有分红送配数据 |
| 涨停板数据 | 没有专门的涨跌停表 |

> **一个刻意的设计**：说不出来的时候，它说"看不了"，而不是找个相近的指标糊弄你。
> 因为糊弄出来的回测，会让你在错误的前提下做决定——那比不给结果更糟。

## 10. 常见问题

**Q：要花钱吗？会用到真钱吗？**
不花钱，全程模拟，没有资金账户，没有任何下单能力。
「我的」页那个「今日还可回测 8/10 次」**目前是界面示意值，不是真实计数**——
限额逻辑还没接上，等接了会在这里说明。

**Q：结果能直接拿去炒股吗？**
不能，也不建议。回测是历史推演，**不代表未来收益，不构成投资建议**。
它的正确用法是**证伪**——帮你快速扔掉那些一听就不靠谱的想法。

**Q：为什么我的策略年化 80%，是不是找到宝了？**
大概率不是。按 §7 那张表逐条排雷：看闭卷考试、看换手率、看收益是不是集中在一两只票。
年化异常高的回测，九成是过拟合或数据问题。

**Q：为什么问它"低估值股票"它说看不了？**
因为当前只有量价数据，没有财务数据。市盈率、市净率都需要财报。
说"便宜的"时它用的是"价格处于近一年低位"——这是**价格位置**，不是估值。确认卡上会写明。

**Q：同一个想法跑两次，结果为什么一样？**
因为回测是确定性的：同样的规则 + 同样的历史数据 = 同样的结果。这是好事，说明可复现。

**Q：改一个参数，要重新从头做吗？**
不用。回首页重新说一句就行，或者从「回测」页里找到旧的看一眼再改。
**注意：改参数之后就是另一个策略了，两个结果要分开看，不要混着比。**

**Q：怎么比较两个策略？**
「回测」页底部「对比策略净值」，选两个一起看曲线。比较时**必须同一区间**，否则没有意义。

**Q：历史记录会丢吗？**
不会了。回测记录（含真实链路跑出来的和本地演示的）会自动存在**这台设备、这个浏览器**里，
刷新、关掉再打开都还在，收藏状态也一起留着。

但下面三种情况仍会丢：**换设备 / 换浏览器 / 手动清浏览器数据**。没有云端账号，跨不了设备。
另外最多保留最近 **20 条**，新的会把最老的挤掉——想要长期留存的结论请自己截图。

**Q：为什么确认卡上的回测区间我不能改？**
改了之后不同策略的结果就没法相互比较了。固定最近 4 年，是为了让所有结果站在同一条起跑线上。

**Q：手机上能用吗？**
可以，H5 就是给手机设计的。加到主屏幕后是全屏的，像 App 一样。

## 11. 术语翻成人话

| 术语 | 人话 |
|---|---|
| **回测** | 用过去几年的真实行情，模拟"如果当时这么做会怎样" |
| **池子 / universe** | 从哪些股票里挑。沪深300、中证500、全市场等 |
| **调仓 / 换仓** | 卖掉不再符合条件、买入新符合条件的 |
| **等权买入** | 每只买一样多的钱。20 只就每只 5% |
| **净值** | 起点算 1.00，涨到 1.2 就是赚了 20% |
| **基准** | 用来对比的参照物，通常是沪深300 |
| **超额收益** | 你比基准多赚的部分。这是唯一能证明"选股有用"的东西 |
| **最大回撤** | 从最高点掉下来最深亏了多少。**最该看的风险数字** |
| **夏普比率** | 每承担一份波动换来多少收益。越高越"划算" |
| **卡玛比率** | 总收益 ÷ 最大回撤。赚的钱值不值这份惊吓 |
| **胜率** | 赚钱的天数占多少 |
| **换手率** | 调仓有多频繁。越高越吃手续费 |
| **样本内 / 样本外** | 「平时练习」和「闭卷考试」。只有后者能证明真本事 |
| **过拟合** | 策略为历史量身定制，换到未来就不灵 |
| **滑点** | 你想按这个价成交，实际成交价差一点。回测里只能估算 |
| **T+1** | 今天买的，明天才能卖。A 股规则 |
| **涨停 / 跌停** | 一天最多涨/跌到某个幅度就停住。涨停时你想买也买不进 |
| **停牌** | 股票暂停交易，持仓卖不掉、也估不了值 |
| **纸面交易** | 只记账、不真下单。观察期用的就是这个 |
